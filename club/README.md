# NOVA Club — version statique

Même club que la version PHP, sans PHP, sans base de données, sans administration.
Il suffit d'envoyer ce dossier tel quel dans `www/club/` (aucune configuration).

- `index.html` : la porte (console, verre brisé, vidéos), puis bouton « Entrer au club »
- `club.html`, `histoire.html`, `evenement-1.html`, `confidentialite.html`
- `media/` : images et vidéos de « Notre histoire » et de l'événement

Pour ajouter un événement ou un chapitre : dupliquer la page concernée et l'éditer à la main.
